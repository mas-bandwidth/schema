# THE LUAU LEG's PINNED FUZZ VECTORS (docs/SPEC-TABLES.md §4.2), in the
# harness's vector-index format (testdata/wire/tables/fuzz-vectors/INDEX.txt):
#
#   <name> <unit> <root> <file>
#
# Each was a red of the Luau leg against the oracle, and each stays as the
# regression gate for its STRICT VERDICT (make/luau-fuzz.mk,
# tables-luau-wire-fuzz-vectors). Its negative control breaks that verdict in a
# scratch copy of the artifact the vector covers, and requires the replay to
# diverge on this vector's name
# (test/conformance/luau/wire-fuzz-vectors-negative-control).
# They live beside the leg rather than in the shared index until every leg
# answers them: the shared index seeds every leg's run.

# A MAP HEADER WHOSE COUNT CROSSES ITS L (§2.8, §3): `0e 02 | 0e 82 06`, a map
# whose count LEB128 runs past its L = 2. The strict read refuses the whole
# load (the Go engine because the header crosses L; the Luau leg because the
# element kind it reads there is a refusal), so the verdict is refused. The
# control restores the tolerant read -- damage no longer discards the load and
# the counters no longer refuse -- and the leg accepts the wire instead.
map_header_count_past_length mapdemo Slots test/conformance/luau/vectors/map_header_count_past_length.bin

# A FORM-1 WIRE AT A FIXED ROOT (§3.2, §3.4): `10 02 | 0e 82 06` on a kind 16
# body, but KeyedConfig is a fixed table, so the strict read refuses the form
# as previous_form before any keyed header is read and the Go engine's
# fixed-root read refuses it too. The control restores the pre-strict
# fixed-form dispatch and the tolerant read, and the leg accepts the wire.
keyed_header_count_past_length tabledemo KeyedConfig test/conformance/luau/vectors/keyed_header_count_past_length.bin

# ILL-FORMED TEXT AT A FIXED ROOT (§3, §3.4): StorePurchase.sku arrives
# well-formed, then again with a payload that is not UTF-8. StorePurchase is a
# fixed table, so the strict read refuses this form-1 wire as previous_form and
# the Go engine refuses it too; the ill-formed occurrence never lands. The
# control restores the pre-strict fixed-form dispatch and the tolerant read,
# and the leg accepts the wire. Found by the random pass at mutant 1527 of seed
# 1 (make tables-luau-wire-fuzz).
text_ill_formed_repeat_reads_default backenddemo StorePurchase test/conformance/luau/vectors/text_ill_formed_repeat_reads_default.bin

# A LIST COUNT PAST THE STORAGE CAP WHOSE SPELLING CROSSES ITS L (§2.9, §3):
# the strict read discards the damaged load, and the Go engine refuses it too.
# The control restores the tolerant read -- the body is framed past its own L,
# damage no longer discards the load, and the partial value survives -- and the
# leg accepts the wire instead.
list_count_cross_length listdemo Album testdata/wire/tables/fuzz-vectors/list_count_cross_length.bin

# A REPEATED MAP KEY MET UNDER A FOREIGN KIND AND THEN UNDER ONE THAT WIDENS

# restores the tolerant last-wins read, and the leg accepts the wire instead.
