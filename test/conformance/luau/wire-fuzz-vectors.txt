# THE LUAU LEG's PINNED FUZZ VECTORS (docs/SPEC-TABLES.md §4.2), in the
# harness's vector-index format (testdata/wire/tables/fuzz-vectors/INDEX.txt):
#
#   <name> <unit> <root> <file>
#
# Each was a red of the Luau leg against the oracle, and each stays as the
# regression gate for the fix that closed it (make/luau-fuzz.mk,
# tables-luau-wire-fuzz-vectors); its negative control is that fix reverted in
# a scratch copy of the emitted units, and this vector's replay must
# diverge (test/conformance/luau/wire-fuzz-vectors-negative-control).
# They live beside the leg rather than in the shared index until every leg
# answers them: the shared index seeds every leg's run.
#
# UNDER THE STRICT READ (docs/rulings.json strict-only-read, refusal-verdict-only)
# the fuzzer compares the VERDICT and the written-back bytes only, never which
# counter or reason refused. A vector found under the tolerant read that both
# readers now refuse for more than one reason stays here as a regression replay,
# and its control is re-aimed at a vector the plant turns from REFUSED into READ.

# A MAP HEADER IS READ AGAINST THE PARENT (§2.8, §3): `0e 02 | 0e 82 06`, a map
# whose count LEB128 runs past its L = 2. The count reads, the element kind 14
# is judged against the map's 13, and one kind_mismatch counts; a reader that
# bounds the header by L calls the count truncated and reports framing damage.
map_header_count_past_length mapdemo Slots test/conformance/luau/vectors/map_header_count_past_length.bin

# A MAP HEADER's FOREIGN ELEMENT KIND REFUSES (§2.8, §4): the clean read refuses

# reads it. Found by the wire fuzzer with that refusal planted out.
map_header_foreign_element_kind listdemo Army test/conformance/luau/vectors/map_header_foreign_element_kind.bin

# A KEYED ARRAY's HEADER IS READ AGAINST THE PARENT (§3, §3.2): `10 02 | 0e 82
