# THE LUAU LEG's PINNED FUZZ VECTORS (docs/SPEC-TABLES.md §4.2), in the
# harness's vector-index format (testdata/wire/tables/fuzz-vectors/INDEX.txt):
#
#   <name> <unit> <root> <file> [retain]
#
# A line ending in `retain` replays on the retaining arm (harness --retain).
#
# Each was a red of the Luau leg against the oracle, and each stays as the
# regression gate for the fix that closed it (make/luau-fuzz.mk,
# tables-luau-wire-fuzz-vectors); its negative control is that fix reverted in
# a scratch copy of the emitted units, and this vector's replay must
# diverge (test/conformance/luau/wire-fuzz-vectors-negative-control).
# They live beside the leg rather than in the shared index until every leg
# answers them: the shared index seeds every leg's run.
