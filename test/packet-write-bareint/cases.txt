# The packet Write of a bare intN / uintN (BareInt.schema), SPEC.md §5.1
# row 11 and PACKET-WIRE-ALGORITHM.md §2 and §2.4.
#
# "refused" means: by the debug build's assert in an assert leg (C, C++, C#,
# Rust, Java, Dart), and by the writer's refusal in every build in an
# every-build leg (Go, JavaScript, Elixir, Lua, Luau, Squirrel, MOO, Goose).
# What an assert leg's release build writes for a refused value is
# unspecified (SPEC.md §5); no case here asks anything of that build.
# "written" means the write succeeds and the value reads back.
#
