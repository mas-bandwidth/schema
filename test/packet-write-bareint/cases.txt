# Shared packet bare-integer width cases (SPEC §5.1 row 11).
# Each line is <name> <value> <verdict>, one case per line.
# "written" means the value fits the declared width and rides as its
# same-width two's-complement (signed) or unsigned pattern.
# "refused" means: by the debug build's assert in an assert leg, by the
# writer's refusal in every build in an every-build leg. Where the target's
# value type is exactly the declared width the refused value cannot be built,
# so that leg has nothing to check.
