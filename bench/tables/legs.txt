# THE TABLES BENCH LEG REGISTRY (bench/tables/README.md).
#
# One line per registered language:  <language> <command>
#
# The command is run from the REPOSITORY ROOT and answers two verbs:
#
#     <command> build            build this leg, or exit 2 if its toolchain
#                                or its runtime checkout is not here
#     <command> run [args...]    run it; args are the runner's own
#                                (--csv, --round K, --wire-dir, --variant-dir)
#
# Exit 2 from `build` prints SKIP and is not a failure: a missing toolchain is
# a missing toolchain. Any other non-zero exit fails the pass.
#
# REGISTERING A PORT IS THIS FILE PLUS ONE COMMAND. Nothing else moves — no
# case in run.sh, no flag, no list anywhere else. The port's row then appears
# on the board beside C++, and the ratio to C++ is its speed bar
# (docs/SPEC-TABLES.md's ladder: same speed, or not significantly slower).
