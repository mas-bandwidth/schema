# THE C++ WARNING RATCHET (make/cpp.mk tables-cpp-clean, docs/PORTING.md J4).
# One line per generated C++ file that still draws a clang++ -Weverything
# warning (less the c++98-compat family): the file, then the warning kinds it
# draws. SHRINK-ONLY: a kind observed in a file that is not listed for it
# fails the gate, and a listed kind that no longer occurs fails until its
# entry is deleted (a kind this clang does not know is not held against it).
# Never add an entry; fix the emitter.
#
# Three kinds sit on the PACKET emitter's files (<Name>.h, <Name>Wire.h) and
# are not the emitter's to clear without altering the packet wire, which Glenn's
# rule forbids for style:
#   padded                   a struct's padding is its layout; removing it moves
#                            fields, which is the wire code's cost.
#   covered-switch-default   -Wcovered-switch-default and -Wswitch-default
#   switch-default           contradict on a switch over every enumerator of an
#                            enum (EnumName's, the union writer's and reader's):
#                            with `default:` the first fires, without it the
#                            second, and only another form of the switch (an
#                            integer switch or an if chain) clears both.
# Every other entry is the TABLE emitter's (internal/codegen/cpptable); the
# plan that empties them is the C leg's, layer by layer.
# `make tables-cpp-clean-census` writes the list as it stands.
