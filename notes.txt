The one thing I would change in bench/go/main.go
------------------------------------------------
The driver's per-op indirection. benchDataDriven takes writeFn/readFn as
function values (main.go:235-237, called at main.go:469), so every timed op
pays one indirect call through a func value; the file's own header
(main.go:16-18) and bench/go/README.md name this as the Go leg's asymmetry
against the C++/Rust template/generic drivers, which inline. That is the whole
of the structural difference between "what the generated codec costs" and "what
the generated codec plus one indirect call costs" — and with the Go codec's
known ~86%-in-the-runtime profile, the call boundary sits inside the timed loop
on every field group.

Change: make the driver generic over the codec so the calls are statically
resolved and the generated read/write can be inlined the way the other legs get
it. The generated codec ships FREE functions, not methods
(generated/bench/go/Bench.go:907+ — bench.WriteBenchMixed /
bench.ReadBenchMixed), so the generic parameter is an adapter with a
statically-known concrete type: define
  type codec[T any] interface {
      Write(*serialize.WriteStream, *T) error
      Read(*serialize.ReadStream, *T) error
  }
and one zero-size adapter per shape, e.g.
  type mixedCodec struct{}
  func (mixedCodec) Write(ws *serialize.WriteStream, v *bench.BenchMixed) error {
      return bench.WriteBenchMixed(ws, v)
  }
  func (mixedCodec) Read(rs *serialize.ReadStream, v *bench.BenchMixed) error {
      return bench.ReadBenchMixed(rs, v)
  }
then `benchDataDriven[bench.BenchMixed, mixedCodec](...)` and call
`c.Write(ws, &instances[...])` inside with `c` a type parameter. Because the
concrete adapter is a static type parameter (not a func value), Go can
devirtualize and inline the adapter into the generated body. The call site in
main.go:469 changes shape but nothing about the corpus, the gates, the
iteration count, the CSV format or the reuse discipline moves; only the per-op
call becomes devirtualizable. Until that lands, the Go gen-family number
carries an indirect call the C++ and Rust numbers do not, and cross-language
ratios should be read with that named (the runner contract already requires
noting it, so this is also the change that lets the note be deleted).
